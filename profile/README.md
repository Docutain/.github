# Docutain SDK

The Docutain SDK brings **document scanning**, **text recognition (OCR)**, **data extraction**,
**photo payment**, **barcode scanning** and **PDF creation** to your apps – known from the
Docutain document management app used by millions of users around the world. It runs
**100 % offline on the device**: no image and no data is sent to a server.
